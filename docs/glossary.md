# Короткий словарь показателей

| Термин | Что означает в YawaFpsHub |
|---|---|
| FPS | Число презентаций кадров выбранного процесса за секунду. Не равно герцовке монитора и не обязательно равно числу показанных на экране кадров. |
| Frame time | Отображаемое число — `1000 / FPS` за последнюю секунду, оценка среднего интервала в миллисекундах, **не** время последнего кадра. При 120 кадрах/с бюджет одного кадра — примерно 8,33 мс. |
| 1 % low / 0,1 % low | Частота по 99-му / 99,9-му перцентилю **времени кадра** в измеренном окне. Помогает заметить редкие просадки, которые скрывает средний FPS; это не средняя частота хвоста и не минимальный FPS. |
| Бюджет кадра | `1000 / целевая частота кадров` мс. Цель по умолчанию берётся из герцовки монитора, но не определяет диагноз узкого места. |
| «Дольше цели» | **Доля измеренных интервалов длиннее целевого времени кадра**, а не потерянные кадры, ETW-события или сетевые пакеты. |
| ETW | Встроенные события Windows для кадров DirectX; приложение собирает их без внедрения DLL в игру. Отсутствие событий или игры — не доказательство нулевого FPS. |
| PDH | Системные счётчики Windows. Загрузка GPU-движка для активной игры отбирается по PID и адаптеру, а не равна общесистемной загрузке. |
| LUID | Идентификатор видеокарты Windows: помогает не смешать показатели двух GPU и сохранить выбор при смене их порядка. |
| VRAM | Память видеокарты. «Использовано» и «всего» имеют разные источники; бюджет DXGI для процесса не выдаётся за полный объём карты. |
| UMC | Контроллер памяти AMD. Экспериментальное чтение действующих таймингов ограничено Matisse/Cezanne DDR4 и требует доступного PawnIO; отсутствие результата не доказывает отсутствие памяти. |
| SPD / XMP / EXPO | SPD хранит паспорт модуля и дополнительные профили. Профиль не равен текущим таймингам; состояние XMP/EXPO по одному SMBIOS не определяется. |
| NVMe SMART | «Использовано» — оценка ресурса контроллером, а не точный срок службы; 255 % означает «255 % или больше». Записанный объём приблизителен: счётчик считает единицы по 512 000 байт с округлением вверх. «Нет данных» не означает нулевой износ. |
| SMBIOS / WMI | Сведения прошивки и Windows о железе, а не независимый замер действующих таймингов или напряжения. |
| tCK | Расчётная длительность такта по сообщённой настроенной скорости (`2000 / МТ/с` нс), доступна в `yawa-probe` с пометкой «не замер»; не прямое измерение контроллера и не действующие тайминги. |
| «Нет данных» / «нужен доступ» / «не поддерживается» | Неизвестная причина пропуска / подтверждённая необходимость включить источник / подтверждённо неподдерживаемое CPU-семейство сборщика. Одно отсутствующее значение само по себе не доказывает второе или третье. |

Подробнее об источниках и ограничениях — в [документации датчиков](sensors.md). Отдельно о сборе добровольных отчётов — [матрица железа](hardware-matrix.md).
