# Происхождение сторонних бинарников

Копии перечисленных файлов использовались для исследования датчиков. Они не требуются
для сборки и не входят в выпускаемый `YawaFpsHub.exe`. Корневые копии исключены из
текущего индекса Git; это **не** удаляет их из старых коммитов. Не публикуйте эти файлы
повторно без проверки условий правообладателей.

| Исследованный файл | SHA-256 локальной копии | Где искать оригинал |
|---|---|---|
| `HWiNFO64.exe` (8.55-6100 по ресурсу PE) | `abc737d525c44d0e56349017fd464f895d2dfbfd696154e8c517121c0c8b0484` | [сайт HWiNFO](https://www.hwinfo.com/download/) |
| `PawnIO_setup.exe` (2.2.0) | `1f519a22e47187f70a1379a48ca604981c4fcf694f4e65b734aaa74a9fba3032` | [PawnIO.Setup 2.2.0](https://github.com/namazso/PawnIO.Setup/releases/tag/2.2.0) |
| `release_0_2_11.zip` | `43608cb89bc84247fef1368a139013f7d043e17db6d6c8dfc9b46bf0905a81f4` | [PawnIO.Modules 0.2.11](https://github.com/namazso/PawnIO.Modules/releases/tag/0.2.11) |

Хеш HWiNFO вычислен по исследованной копии; происхождение этой конкретной копии
не подтверждено правообладателем. У PawnIO хеши сверены с digest официальных
release assets (см. [аудит](sensors.md#аудит-кандидата-kernel-модуля-pawnio)).
HWiNFO не запускается и не используется приложением. Исследование локального файла
описано в [документации датчиков](sensors.md#проверка-загруженного-hwinfo64exe).

Не путать удалённые установщик и архив релиза с файлами в
[`third_party/pawnio`](../third_party/pawnio/README.md): подписанные SYS/INF/CAT,
два аппаратных модуля и архив соответствующих исходников остаются частью сборки.
Их контрольные суммы проверяются при конфигурации в [`cmake/pawnio.cmake`](../cmake/pawnio.cmake);
сборка ничего не скачивает.
