    Источники данных

    Проверка выполняется при запуске, недоступное честно помечается

    проверено
    • ETW · кадры Microsoft-Windows-DXGI и D3D9, Present_Start работает нужны права администратора
    • PDH · процессор, диски, сеть те же счётчики, что у диспетчера задач работает без прав администратора
    • PDH · загрузка GPU GPU Engine, движок 3D активного адаптера работает Windows 10 1709 и новее
    • DXGI · адаптеры и видеопамять LUID, объём, бюджет QueryVideoMemoryInfo работает ядро драйвера, без установки
    • NVML · температура и питание GPU nvml.dll из драйвера NVIDIA работает только NVIDIA
    • Датчики CPU и чипсета нужен драйвер доступа к MSR и SMBus нет данных не ставим драйвер ради безопасности
