# Приватность

YawaFpsHub работает локально. В текущей версии нет аккаунта, телеметрии,
автоматической отправки журналов, снимков или сведений о железе и фоновой проверки
обновлений. Приложение не делает собственных сетевых запросов; получение выпусков
через браузер или GitHub — действие пользователя.

## Что хранится на компьютере

- Показатели кадров, процессов и датчиков обрабатываются в памяти приложения.
- Настройки записываются в `%LOCALAPPDATA%\YawaFpsHub\YawaFpsHub.ini`.
- Журнал ошибок и запуска записывается в том же каталоге как `YawaFpsHub.log`;
  при ротации может остаться `YawaFpsHub.log.1`. Записи могут содержать имена
  устройств, пути к файлам и диагностические сообщения.
- Если каталог профиля Windows недоступен, настройки и журнал сохраняются рядом
  с exe. Старые файлы рядом с exe могут быть однократно скопированы в профиль.
- При подтверждении UAC для аппаратных датчиков Windows устанавливает встроенный
  подписанный драйвер PawnIO. Он может оставаться зарегистрированным после выхода
  из программы; подробности — в [README](README.md#низкоуровневые-датчики-cpu-pawnio).

Экран «Баланс» позволяет по явному действию открыть предпросмотр диагностической
карточки и сохранить её как PNG или пакет `.yawa`. По умолчанию кадра игры нет;
его можно отдельно захватить после переключения в игру. Desktop Duplication может
захватить также наложенные поверх игры окна, уведомления и оверлей. Перед
сохранением проверьте итоговую карточку, закройте чувствительные области
непрозрачными масками перетаскиванием мыши или полностью уберите кадр.
Исходный кадр не записывается отдельно; PNG и `screen.png` в `.yawa` содержат
только показанную карточку. Остальные поля пакета не включают сырые журналы,
пути, имена процессов и серийные номера. Автоматического сохранения или отправки
нет. Команда `YawaFpsHub.exe --report=<локальный-файл.yawa>` только проверяет
указанный пакет и печатает статус и данные сессии в stdout; сетевые пути не
принимает. Просмотр `.yawa` по кнопке на экране «Баланс» декодирует PNG только
в памяти: чужой пакет может содержать личные данные в кадре и недостоверные числа;
содержимое на диск не извлекается и не отправляется. Команда
`--report=<локальный-файл.yawa> --html=<новый-файл.html>` только по запросу
создаёт самодостаточный HTML со встроенным изображением; не отправляет файл,
не загружает внешние ресурсы и не перезаписывает существующий HTML. Перед
публикацией проверьте, не остались ли в кадре личные сведения.
Вывод явного SPD-пробника может содержать **партномер модуля** — это
паспортная подпись без серийного номера; проверьте её перед публикацией.
Команда `YawaFpsHub.exe --probe --dump=memory` запускается только явно, выводит
ограниченные сырые регистры UMC в stdout и не пишет файл сама; для перенаправления
в файл пользователь должен указать его сам. Она не устанавливает драйвер и не
запрашивает UAC, но уже доступный PawnIO нужен для чтения. Дамп способен раскрыть
конфигурацию памяти: перед публикацией проверяйте его так же, как журнал.

Любой отправленный в GitHub Issue снимок, фрагмент журнала, дамп или вывод диагностической
`yawa-probe.exe` публикует **сам пользователь**. Эти материалы могут содержать
имена процессов, модель железа, локальные пути и данные других окон. Перед публикацией
проверьте их и скройте личные сведения. [Шаблон обращения](.github/ISSUE_TEMPLATE/diagnostics.md)
не требует прикладывать файлы.

Приложение не удаляет пользовательские настройки и журналы при закрытии. Их можно
удалить вручную после выхода из приложения; если драйвер установлен, удалять его
нужно отдельно с учётом других программ, которые его используют.
